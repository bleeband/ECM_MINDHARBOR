ECMMindHarbor est une plateforme sécurisée et bienveillante de soutien en santé mentale. Elle permet le suivi du bien-être personnel, l'accès à des ressources adaptées et la participation à des groupes de soutien thématiques, le tout en garantissant la stricte confidentialité des données de santé.


## 🚀 Installation et Démarrage

### 1. Cloner le dépôt
```bash
git clone https://github.com/bleeband/ECM_MINDHARBOR.git
cd ecm_mindharbor

```


### 2. Configuration du Serveur (Backend)

```bash
cd server
npm install

```
